FanFrame brings a sharp-cornered, low-saturation dark and light aesthetic and reading/interaction refinements to Paseo.

It contributes two Appearance themes (FanFrame Dark and FanFrame Light), a cross-platform "Status · By Project" custom sidebar view, interactive question cards that turn plain-text numbered option prompts into clickable choices, a cross-device file transfer button in the composer (with optional image compression and chunked upload for arbitrary files up to 50 MiB), inline visualization cards and local media previews with custom sharp-cornered audio/video players, and optional desktop/web refinements including 0px corners, low-saturation Markdown syntax colors, perceptually stepped three-tier prose brightness layering, smooth GPU disclosure motion with bottom-only auto-scroll guarding, project-colored sidebar titles, and a three-column sidebar navigation grid.

## Setup

Select FanFrame Dark or FanFrame Light under Settings -> Appearance, optionally choose "Status · By Project" under Settings -> Sidebar -> Sidebar view, and toggle individual visual and interaction modules or extra media preview directories under Settings -> Plugins -> FanFrame. No external accounts, tokens, or extra binaries are required. Works on Paseo 0.17.0 or later across desktop and web clients; native mobile clients receive the themes, custom sidebar view, interactive question cards, and cross-device file and image timeline items.

## Capabilities, data access, and limits

- **Themes and web/desktop visual modules**: Visual toggles are saved locally in browser `localStorage`. All injected styles and observers clean up automatically when disabled or removed, and coordinate as a single shared instance across multi-host sessions.
- **Status · By Project sidebar view**: Cross-platform custom sidebar view (desktop, web, iOS, Android) staging running and recently active projects at the top with a user-configurable time window, followed by flush-left status and project groups with time, workspace-initial, and manual sort modes. Collapse state, time window, sort mode, manual order, and filters are stored in device-scoped Paseo plugin settings (`sidebar-status-projects`) and never leave the client.
- **Interactive question cards**: Detects structured `[1] / [2]` option lists in assistant messages (such as ACP providers that fall back to text questions) and sends the selected choices back as a normal user message to the active agent.
- **Cross-device file transfer**: Supports images and arbitrary files up to 50 MiB (up to 6 files per message) via chunked upload and download. Images are compressed on the client by default (with an optional original-quality switch) and forwarded as image attachments; non-image files are saved untouched under `~/.paseo/plugin-data/paseo-fanframe/shared-files/` (automatically pruned by age and count, while keeping legacy `shared-images/` readable) and forwarded as native uploaded file attachments to the active agent provider.
- **Inline media previews**: When an assistant message includes a `fanframe-media` (or `dsh-media`) fenced JSON block with an absolute path, the server handler resolves symlinks (`realpath`) and by default strictly restricts inspection and file reads to files inside the active conversation's workspace directory (`agent.cwd`), plus any additional host directories explicitly added by the user under Settings -> Plugins -> FanFrame (default: none). Files outside allowed roots are blocked on the server without reading metadata or contents; users can explicitly add a directory from the blocked notice card or Settings, or explicitly opt in to the per-host "allow all paths" switch (off by default) under Settings -> Plugins -> FanFrame. Supported formats remain bounded by an extension allowlist and per-type size limits. Downloads stream in chunks with a live progress bar and are cached locally (in-memory LRU plus browser IndexedDB, validated by size and mtime) so switching conversations or reloading avoids redundant re-downloads.
- **Inline visualization cards**: Registers the `fanframe_visualize` agent tool and a short session guidance prompt so agents can emit self-contained HTML/SVG/canvas cards rendered inside sandboxed iframes (`sandbox="allow-scripts"`, CSP `default-src 'none'`, no network access).
